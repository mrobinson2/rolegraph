# Documentation catalog

Every document in the repository, what it is for, and who reads it. Read order
for someone new: `README.md` → `docs/BRIEF.md` → `docs/HANDOFF.md` →
`docs/ARCHITECTURE.md`, then whatever your task needs below.

## Repository root

| Document | Audience | What it is |
|---|---|---|
| [README.md](../README.md) | Customers, evaluators, contributors | Public front page. Product promise, `docker compose up` quick start, five-minute demo tour, screen-by-screen overview with screenshots, findings list, configuration and security posture, project layout. |
| [CLAUDE.md](../CLAUDE.md) | AI coding agents (Claude Code) | Project instructions checked into the repo: fixed architecture decisions (stack, modular monolith layout, import schema, privileged roles), working rules (security first, deterministic findings, plain English), MVP definition of done. |
| [AGENTS.md](../AGENTS.md) | AI coding agents (Codex and others) | Cross-tool agent entry point. Points at HANDOFF → BRIEF → ARCHITECTURE, gives quick start commands and boundaries. |
| [KICKOFF_PROMPT.md](../KICKOFF_PROMPT.md) | Repository owner | Historical: the first prompt used to start the MVP build from an empty repo. Kept for provenance; not an active instruction. |

| Document | Audience | What it is |

| [ARCHITECTURE.md](ARCHITECTURE.md) | Engineers | Why the code is shaped this way: modular monolith, SQLite over a graph DB, snapshots from day one, the resolution model (identity → membership → assignment → role → scope), findings engine, web layer, security posture, what was deliberately left out. |
| [HANDOFF.md](HANDOFF.md) | Engineers and agents picking the repo up cold | Engineering handoff. ## Generated, ignored, or not documentation

- `artifacts/` — gitignored output of local drift demo runs (`report.md`, JSON). Regenerate with `scripts/demo_rbac_drift.py`.
- `.pytest_cache/README.md` — pytest's own file, not ours.
- `data/demo/contoso.json` — generated from `scripts/generate_contoso_demo.py`; the script's `$notes.intentionalIssues` block documents every planted RBAC problem. Edit the script, not the JSON.
